# RAG_chatbot
## RAG Chatbot using Gradio and LangChain
- An AI-powered RAG (Retrieval-Augmented Generation) chatbot that answers user questions based on uploaded PDF documents using vector embeddings and Large Language Models (LLMs).

## Project Overview :
- The chatbot retrieves relevant information from the document using vector search and generates intelligent answers using an LLM.

- The project is built using:
1. Python
2. Gradio
3. LangChain
4. FAISS / Chroma Vector Store
5. Hugging Face Embeddings
6. Ollama LLM model

## Features :
1. Upload PDF documents
2. Extract text from PDFs
3. Create embeddings from document chunks
4. Store embeddings in vector database
5 .Ask questions from uploaded PDFs
6. Context-aware AI responses
7. Interactive Gradio UI
8. Local project execution

## Tech Stack :
   Technology       --->     	Purpose
1. Python	        --->   Backend Development
2. Gradio	        --->     User Interface
3. LangChain	     --->      RAG Pipeline
4. FAISS         	  --->   Vector Database
5. Hugging Face	  --->     Embeddings
6. Ollama           --->    LLM Integration
